KEUANGANKU v3 - CARA MENDAPATKAN APK (GRATIS, TANPA PEMBUAT APK PIHAK KETIGA)

1. Buat repo di github.com (nama: keuanganku), lalu upload SEMUA isi zip ini
   (termasuk folder .github). File harus langsung di root repo.
2. Buka tab Actions > "Build APK" > Run workflow. Tunggu sekitar 5-8 menit.
3. Buka hasil run tersebut > bagian Artifacts > unduh "KeuanganKu-APK" (zip berisi app-debug.apk).
4. Ekstrak, kirim ke HP, buka file APK, izinkan "Instal dari sumber tidak dikenal".
5. Buka aplikasi > menu Lainnya > Pengingat dan alarm > Simpan dan jadwalkan > izinkan notifikasi.

Alternatif tanpa APK: pasang di GitHub Pages lalu "Instal aplikasi" dari Chrome (alarm saat
aplikasi tertutup hanya jalan di versi APK).

iOS: file IPA tidak bisa dibuat tanpa Mac dan akun Apple Developer. Di iPhone gunakan
Safari > Bagikan > Tambah ke Layar Utama.

Data lama (v2) otomatis dipindahkan saat pertama dibuka di alamat yang sama.

CATATAN v3.1: jika tab Actions tidak menampilkan "Build APK", folder .github belum ikut
terunggah (folder tersembunyi). Buat manual: di GitHub tekan Add file > Create new file,
ketik nama  .github/workflows/build-apk.yml  lalu tempel isi file build-apk.yml.txt.

CATATAN v3.4 (PEMBARUAN TANPA KEHILANGAN DATA): unggah juga file debug.keystore ke root repo.
Dengan kunci tetap ini, APK baru bisa dipasang menimpa APK lama dan data tetap ada.
Khusus pemasangan pertama versi ini: APK lama (kunci acak) harus dihapus dulu, jadi
SALIN CADANGAN DATA dulu di Lainnya > Cadangan data. Setelah itu, update berikutnya aman.

CATATAN v3.5 (NOTIFIKASI PEMBARUAN): setiap update, naikkan angka APP_VER di index.html
(misal "3.5" jadi "3.6"). Build APK otomatis membuat Release di GitHub berisi KeuanganKu.apk.
Aplikasi mengecek Release terbaru saat dibuka dan ada internet; jika lebih baru, muncul
banner "Ada pembaruan" dengan tombol Unduh. Repo harus PUBLIK agar pengguna bisa mengunduh.
